AI 서비스

유튜브 댓글 분석 AI 서비스

기획 배경: 영상 콘텐츠 크리에이터와 마케팅 기업이 수천 개의 시청 반응을 손쉽게 이해하고 유의미한 비즈니스 피드백을 가려내기 위해 고안했습니다.

핵심 기능: 구글 스프레드시트 트리거를 통해 유튜브 API를 활용하여 지정 시간에 최신 피드백 댓글을 전송받습니다. 이후 Gemini API를 연계, 댓글 데이터를 감정 분석(부정/긍정/의견) 처리하여 실시간 데이터베이스에 누적합니다.

교육적 효과: 학생 및 일반인 수강생들은 이 프로젝트를 통해 API 연동 설계, JSON 파싱, 기본 인공지능 프롬프트 지시어 설계까지의 필수 지식을 종합 실습할 수 있습니다.

사용한 핵심 기술 스택

Google Apps Script Gemini API YouTube API
업무 관리

구글 시트 연동 칸반 보드

기획 배경: 협업을 위해 복잡하고 유료인 툴 대신, 누구나 쉽게 사용하는 구글 시트를 기반으로 완벽한 UI 칸반 보드를 활용하고자 하는 소상공인과 스타트업을 위해 개발했습니다.

핵심 기능: 드래그 앤 드롭 방식을 이용해 태스크의 진행 단계(진행 전, 진행 중, 완료)를 자유롭게 변경하고, 해당 이벤트가 구글 드라이브 클라우드 시트 내부에 즉시 쓰기/읽기 동기화되는 서비스입니다.

교육적 효과: 비전공자도 HTML 요소를 제어하고 실전 연동 자바스크립트의 비동기 호출(Fetch) 로직을 손쉽게 이해하는 실무 개발 기반 다지기용으로 훌륭한 만족도를 보여줍니다.

사용한 핵심 기술 스택

HTML5 & CSS3 JavaScript ES6 Google Sheets API
대시보드

실시간 세일즈 트래커

기획 배경: 기업 임직원의 신속한 의사결정을 돕는 비주얼 데이터 플랫폼의 필요성을 절감하여, 누구나 데이터를 쉽게 읽을 수 있는 세련된 차트와 트래커 화면을 직접 기획했습니다.

핵심 기능: 입력 폼을 통해 매출 데이터가 쌓이면 주 단위, 일 단위 판매 추이 그래프가 리프레시 없이 동적으로 업데이트되고, 목표 대비 달성률이 원형 진척율 UI로 자동 표시됩니다.

교육적 효과: 모던 프론트엔드 프레임워크인 React의 컴포넌트 라이프사이클 관리와 상태 값 흐름, 그리고 외부 차트 라이브러리 라이프 결합 구조를 습득하기 최적화된 고급 실용 예제입니다.
