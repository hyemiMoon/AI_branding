# **SW.AI for NEXT GEN \- 교육 강사 포트폴리오 랜딩 페이지**

초등, 중등, 고등학생을 대상으로 하는 SW 및 AI 교육 전문가를 위한 모던하고 역동적인 랜딩 페이지입니다. 미래 세대(Next Gen)를 위한 교육 철학을 세련된 UI로 담아냈습니다.

## **🚀 주요 특징**

* **반응형 디자인**: 모바일 및 데스크톱 환경 모두에 최적화된 레이아웃.  
* **역동적인 애니메이션**: Animate.css와 맞춤형 CSS 애니메이션을 활용한 생동감 있는 사용자 경험.  
* **연령별 맞춤 섹션**: 초등, 중등, 고등 교육 과정에 대한 전문적인 설명 카드.  
* **이메일 복사 기능**: 클릭 한 번으로 강사의 이메일을 복사할 수 있는 편리한 연락 기능.  
* **모던한 UI**: Tailwind CSS를 활용한 세련된 그라데이션과 타이포그래피.

## **🛠 기술 스택**

* **HTML5**: 웹 표준 구조 설계  
* **Tailwind CSS**: 유틸리티 우선 프레임워크를 이용한 스타일링  
* **JavaScript (Vanilla)**: 이메일 클립보드 복사 및 토스트 메시지 시스템 구현  
* **Font Awesome**: 고품질 테크 아이콘 적용  
* **Animate.css**: 선언적 애니메이션 효과
